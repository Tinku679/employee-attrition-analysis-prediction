# Employee Attrition Analysis & Prediction

## 📌 Project Overview

Employee attrition is a common business challenge because employee turnover can
affect productivity, workforce planning, and day-to-day operations.

In this project, I analyzed employee data to understand the factors and patterns
associated with employee attrition. I also built a Machine Learning model to
predict whether an employee is likely to leave the company or stay.

This project demonstrates my practical understanding of **Data Cleaning, EDA,
Data Visualization, Feature Preparation, and Machine Learning** using Python.

---

## 🎯 Problem Statement

The objective of this project is to analyze employee data, identify patterns
related to employee attrition, and predict whether an employee will leave the
company or stay.

The analysis focuses on questions such as:

- Which employee factors are associated with attrition?
- Is salary level related to employee attrition?
- Is the number of projects related to employees leaving?
- Does time spent in the company show any relationship with attrition?
- How are work accidents and promotions related to attrition?
- Can employee-related information be used to predict attrition?

---

## 📊 Dataset

The dataset contains employee-level information including:

- Satisfaction Level
- Last Evaluation
- Number of Projects
- Average Monthly Hours
- Time Spent in Company
- Work Accident
- Promotion in Last 5 Years
- Department
- Salary
- Employee Attrition (`left`)

### Target Variable

`left`

- `0` → Employee stayed
- `1` → Employee left
